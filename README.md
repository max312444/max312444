## 自己紹介 | About Me

こんにちは、조원준（チョ・ウォンジュン）です。
Web アプリケーションおよび AI 技術を中心に学習・開発しています。

- API を用いたデータ取得から画面表示までの一連の流れを重視

- 可読性・保守性を意識したコード構成
- 取得したデータを加工・整理し、意味のある形で扱うことを意識
- 学習目的に留まらず、動作する形まで実装することを重視
