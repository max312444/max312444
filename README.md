## プロジェクト | Projects

- **AI スケジュール管理システム（卒業制作）**  
  Claude API の Function Calling を活用したスケジュール管理 Web アプリ（FastAPI・Vue.js・PostgreSQL）  
  → add_schedule / get_schedule / delete_schedule / check_conflict の 4 ツールを設計・実装

- **AI テキスト RPG システム**  
  Claude API をゲームマスターとして活用したフルスタックテキストアドベンチャーゲーム（FastAPI・Vue 3・PostgreSQL・pgvector）  
  → Tool Use による戦闘・インベントリ・移動のゲーム状態管理を実装  
  → sentence-transformers + pgvector による RAG メモリ機能、SSE ストリーミングによるリアルタイム内レーション出力を実現  
  → Docker Compose によるフルスタック構成

- **ストレートネック測定 Web アプリケーション**  
  Web カメラ入力を用いたリアルタイム姿勢分析 Web アプリ（FastAPI・Vue.js・PostgreSQL・MediaPipe・Google OAuth）  
  → カメラ入力処理、姿勢データ算出、結果の可視化までを一貫して実装

- **AI 自律走行 RC カープロジェクト**  
  カメラ映像のみで走行判断を行う End-to-End 自律走行システム（Python・OpenCV・CNN・Jetson Nano）  
  → 学習用データ作成から推論モデル実装、走行検証までを経験  
  → 認識精度 19% → 88% を達成

- **サッカー情報掲示板 Web アプリケーション**  
  外部 API を活用したニュース・リーグ順位・試合日程表示 Web サービス（Node.js・Express・Vue.js・MySQL）  
  → 複数 API のデータ取得・加工・画面表示を実装

- **Bannote 自習室予約サービス（バックエンド担当）**  
  学内向け自習室予約 Web サービスのバックエンド開発（Ruby on Rails・gRPC・MSA 構成）  
  → 予約作成・キャンセル・時間帯管理などの API 設計および実装  
  → データ整合性を意識したロジック設計と DB 操作を経験
